Brücke einrichten

Mit einer Brücke zu Hause erreichst du deine Drucker auch unterwegs und aus dem Browser – Status, Kamera, Drucken, Zeitraffer. Die Brücke baut nur eine Verbindung nach draußen auf: im Router musst du nichts freigeben, deine Drucker bleiben unsichtbar im Internet.

Läuft bei dir schon ein Unraid-Server, Home Assistant oder ein Docker-Rechner? Dann brauchst du keine neue Hardware: dort einfach Mit PocketPrint3D Cloud verbinden einschalten (Unraid-Vorlage, Option im Home-Assistant-Add-on) – siehe Hilfe. Diese Seite ist für alle anderen.

Warum mit Kabel? Dann musst du kein WLAN einrichten, die Verbindung ist zuverlässiger, und die Brücke findet deine Drucker im Heimnetz von selbst. Ein Raspberry Pi Zero 2 W (nur WLAN) geht auch, ist aber schwieriger einzurichten.

2. Einrichten – etwa 20 Minuten

  1. Raspberry Pi Imager installieren

    Auf deinem Computer: raspberrypi.com/software → herunterladen und installieren (Windows, Mac oder Linux).

  2. Karte beschreiben

    microSD-Karte in den Computer stecken, Imager starten und wählen: Gerät: Raspberry Pi 3 (bzw. dein Modell) → Betriebssystem: Raspberry Pi OS (other) → Raspberry Pi OS Lite (64-bit) → Speicher: deine SD-Karte.

  3. Einstellungen vorab festlegen

    Wenn der Imager fragt, ob du Einstellungen anpassen willst: Ja / Einstellungen bearbeiten. Hostname: pocketprint3d · Benutzername: pi + ein Passwort, das du dir merkst · WLAN nicht einrichten · unter Dienste: SSH aktivieren mit Passwort. Speichern, dann Schreiben – dauert ein paar Minuten.

  4. Pi anschließen

    Karte in den Pi stecken, Netzwerkkabel zum Router, zuletzt das Netzteil einstecken. Zwei Minuten warten – die grüne Lampe blinkt beim Starten.

  5. Mit dem Pi verbinden

    Am Computer ein Befehlsfenster öffnen – Windows: Start → Eingabeaufforderung eintippen; Mac: Programme → Dienstprogramme → Terminal. Dort eingeben:

    ssh pi@pocketprint3d.local

    Beim ersten Mal yes eintippen, dann dein Passwort (es wird beim Tippen nicht angezeigt – das ist normal).

  6. Brücke installieren – ein einziger Befehl

    Diese Zeile kopieren, ins Fenster einfügen (Rechtsklick bzw. Strg+V / ⌘V) und Enter drücken:

    curl -fsSL https://pocketprint3d.com/install-bridge.sh | sh

    Das dauert auf einem Pi 3 etwa 5–10 Minuten. Am Ende erscheint groß dein Kopplungscode, z. B. K7Q4-M2ZX.

  7. Code in der App eingeben

    In der PocketPrint3D-App (oder unter app.pocketprint3d.com): Einstellungen → Erweitert → Unterwegs drucken → Code eingeben → Verbinden. Danach Drucker über die Brücke hinzufügen – die Brücke sucht deine Drucker selbst. Fertig!

Danach musst du dich um nichts kümmern. Die Brücke startet nach einem Stromausfall von selbst und holt sich nachts neue Versionen. Den Code zeigt jederzeit wieder: pocketprint3d-code (nach Schritt 5).

Ohne Befehlsfenster am Computer

Du kannst den Pi auch direkt bedienen: einen Bildschirm (HDMI) und eine USB-Tastatur anschließen, mit pi und deinem Passwort anmelden und den Befehl aus Schritt 6 eintippen.

Wenn etwas nicht klappt

„pocketprint3d.local“ wird nicht gefunden
Schau in deinem Router nach der Adresse des Pi (bei einer FRITZ!Box: Heimnetz → Netzwerk, Gerät „pocketprint3d“) und verbinde dich mit dieser Adresse, z. B. ssh pi@192.168.178.42. Leuchtet die Lampe an der Netzwerkbuchse?
„32-bit“-Meldung beim Installieren
Es wurde das 32-Bit-System geschrieben. Karte im Imager neu beschreiben mit Raspberry Pi OS Lite (64-bit).
Der Code ist abgelaufen
Er gilt 10 Minuten; danach erscheint von selbst ein neuer. Anzeigen mit pocketprint3d-code.
In der App steht „Brücke offline“
Hat der Pi Strom und steckt das Netzwerkkabel? Nach dem Einstecken dauert es etwa zwei Minuten.

Neugierig, was der Befehl macht? Das Skript lässt sich vorher lesen: install-bridge.sh. Es installiert Docker und die Brücke nach /opt/pocketprint3d-bridge. Fragen oder Probleme: GitHub.
