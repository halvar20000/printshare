Bien démarrer

Il vous faut : votre imprimante 3D allumée et connectée à votre Wi-Fi (Elegoo Centauri Carbon, une imprimante Klipper, une Prusa avec PrusaLink, une Bambu Lab en mode LAN ou une installation OctoPrint), votre téléphone sur le même Wi-Fi et une adresse e-mail. Rien à installer à la maison.
  1. Installez l'application

    Android : actuellement en test bêta sur Google Play. iPhone : bientôt. Sur un ordinateur, vous pouvez utiliser app.pocketprint3d.com avec le même compte.

  2. Inscrivez-vous – juste avec votre e-mail

    Appuyez sur Sign up for free, saisissez votre e-mail puis le code à 6 chiffres que vous recevez. Pas de mot de passe.

  3. Ajoutez votre imprimante

    Appuyez sur Add printer. L'application cherche sur votre Wi-Fi et affiche votre imprimante – appuyez dessus, puis sur Save. Prusa : saisissez aussi le mot de passe PrusaLink (écran de l'imprimante → Settings → Network). OctoPrint : une clé API (OctoPrint → Settings → Application Keys). Bambu Lab : le code d'accès (voir plus bas).

  4. Trouvez un modèle

    Dans Discover, cherchez sur Printables ou Thingiverse. Ou partagez le lien d'un modèle depuis votre navigateur avec PocketPrint3D, ou ouvrez un fichier (STL, 3MF, OBJ, STEP) avec Choose a file.

  5. Préparez l'impression

    Choisissez le matériau et la qualité – les réglages par défaut conviennent à la plupart des modèles. Des supports seulement pour les surplombs. Puis Prepare print : après environ une minute, vous voyez la durée d'impression, le filament et un aperçu.

  6. Imprimez

    Vérifiez l'aperçu, appuyez sur Print et confirmez que le plateau est vide et que le bon matériau est chargé. Rien ne démarre jamais sans cette confirmation.

  7. Suivez l'impression

    L'onglet Printers affiche la progression, le temps restant et les températures. C'est là que vous mettez en pause, reprenez ou annulez. Dans Jobs, l'impression apparaît comme « Printing », puis « Printed » ou « Cancelled ». Encore une fois ? Ouvrez la tâche et appuyez sur Print again.

Si quelque chose ne marche pas

L'imprimante n'est pas trouvée
Est-elle allumée et votre téléphone est-il sur le même Wi-Fi (pas en données mobiles, pas sur un réseau invité) ? Un VPN sur le téléphone (p. ex. Tailscale) peut aussi empêcher la recherche : désactivez-le un instant. Appuyez sur Search again, ou Enter the address yourself – l'imprimante affiche son adresse IP dans son menu réseau.
« Not reachable »
À la maison, l'application parle directement à l'imprimante. Hors de chez vous, cela ne marche qu'avec un pont (voir plus bas).
Le fichier est sur l'imprimante mais l'impression n'a pas démarré
Certaines imprimantes ignorent parfois l'ordre de démarrage. Lancez le fichier sur l'écran de l'imprimante – il y est déjà.
La tâche indique encore « Printing » alors que l'impression est finie
La tâche l'apprend de l'imprimante : avec un pont en moins d'une minute, sans pont quand votre téléphone est à la maison et que l'application affiche l'onglet Printers. Ouvrez-le une fois sur votre Wi-Fi.
Le modèle est trop grand ou le tranchage échoue
Essayez une taille plus petite (Size dans « On the plate ») ou un autre fichier du modèle.

Piloter l'imprimante

Sur l'onglet Printers, le bouton Control ouvre une page par imprimante avec tout le reste – jamais pendant une impression :

  • Températures avec courbe, préchauffage PLA/PETG, refroidissement ; ventilateurs, éclairage, vitesse.
  • Move : prise d'origine (Home all axes), puis déplacer X, Y et Z par pas de 0,1 à 100 mm. Faites d'abord la prise d'origine ; attention en descendant Z, la buse peut toucher le plateau.
  • Extruder and filament : choisissez le matériau (PLA 220 °C, PETG 250 °C …) puis Load filament ou Unload filament – la buse chauffe d'abord, puis le filament est tiré vers l'intérieur ou ressorti. Pour charger, poussez le filament jusqu'en butée dans l'extrudeur. Sur la Centauri Carbon cela s'exécute comme une courte tâche sur l'imprimante ; sur une Bambu Lab, choisissez le bac de l'AMS.
  • Macros (imprimantes Klipper) : les commandes configurées sur votre imprimante, p. ex. le nettoyage de la buse.

Imprimer de partout (pont)

Vous débutez ? Installer un pont sur un Raspberry Pi – liste d'achats (environ 60 €) et image de carte prête à l'emploi : l'écrire, brancher câble et alimentation, appuyer sur « Connect » dans l'application.
  1. Faites tourner un pont à la maison : sur votre propre serveur PocketPrint3D, activez Connect to PocketPrint3D Cloud (modèle Unraid, option du module Home Assistant, ou page web du serveur → Settings). Sans serveur : la petite image Docker ghcr.io/halvar20000/printshare-bridge.
  2. Le pont affiche un code (journal du conteneur ou sa page web).
  3. Dans l'application : Settings → Advanced → Print from anywhere, saisissez le code, Connect.
  4. Les imprimantes du pont apparaissent dans votre compte, marquées « through a bridge ». D'autres imprimantes : Add a printer through the bridge – adresse et mot de passe sont chiffrés pour que seul votre pont puisse les lire.

Connexion sortante uniquement : rien à ouvrir sur votre box, vos imprimantes restent hors d'Internet.

Sur l'ordinateur

  • Ouvrez app.pocketprint3d.com et connectez-vous avec la même adresse e-mail – mêmes imprimantes, tâches et bobines.
  • Glissez un fichier de modèle sur la page pour commencer.
  • L'impression depuis le navigateur marche pour les imprimantes derrière un pont. Les autres sont marquées « Phone only » : lancez-les dans l'application, ou téléchargez le G-code.

Envoyer depuis OrcaSlicer

Pourquoi passer par PocketPrint3D ? OrcaSlicer peut souvent joindre votre imprimante directement – mais alors l'impression contourne PocketPrint3D. En passant par PocketPrint3D :
  • Les bobines restent justes : le filament utilisé est décompté comme pour toute autre impression.
  • De partout : trancher sur le portable au travail, l'imprimante à la maison imprime – via votre pont.
  • Une seule vue d'ensemble : l'impression apparaît dans l'application et le navigateur – aperçu, progression, caméra, pause.
  • Vérifier d'abord, lancer ensuite : « Upload » prépare l'impression ; vous la lancez depuis le téléphone quand le plateau est libre, en choisissant bobine et emplacement.

Vous ne gérez pas de bobines et n'imprimez qu'à la maison ? Alors l'envoi direct depuis OrcaSlicer convient tout aussi bien. Vous n'ajoutez pas de nouvelle imprimante dans OrcaSlicer – vous donnez un autre chemin à votre vraie imprimante : via PocketPrint3D.

  1. Dans l'application ou le navigateur : Settings → your printer → Send from OrcaSlicer on your computer → Create access. Vous obtenez une adresse et une clé (affichée une seule fois).
  2. Dans OrcaSlicer : icône Wi-Fi à côté de l'imprimante (ajouter une imprimante physique) → type d'hôte Octo/Klipper → saisir l'adresse et la clé → Test.
  3. Après le tranchage : Upload – l'impression attend comme tâche dans l'application. Upload and print – démarre tout de suite sur une imprimante derrière un pont et décompte la dernière bobine utilisée.

Bobines de filament

  • Settings → Advanced → Filament spools : gardez vos bobines dans votre compte PocketPrint3D, ou connectez votre propre Spoolman – c'est vous qui choisissez. Vous passez à la cloud plus tard ? Un appui copie toutes les bobines de votre Spoolman dans le compte.
  • À l'impression, choisissez la bobine pour chaque couleur. Vous êtes averti si l'une ne suffit pas ou si le matériau ne correspond pas.
  • Le filament utilisé est décompté à la fin de l'impression. Avec les bobines dans le compte, cela marche aussi application fermée (imprimantes derrière un pont).
  • Nouvelles bobines : choisissez-les dans la base de filaments, ou approchez le téléphone d'une bobine NFC OpenPrintTag (Android). N'importe quel autocollant NFC peut aussi être associé une fois à une bobine.

Timelapse

  • Sur l'écran de vérification, activez Record a time-lapse (désactivé par défaut) – ou une fois pour toutes dans Settings → Time-lapse. Le bouton apparaît pour les imprimantes avec une caméra que votre serveur ou un pont peut joindre.
  • Pendant l'impression, une image est prise par couche (Centauri Carbon, Klipper, Bambu Lab) ou toutes les 30 secondes (Prusa, OctoPrint).
  • À la fin, une courte vidéo est créée. Sur la tâche : Watch the time-lapse – avec Download the video. Elle est supprimée avec la tâche au bout de 14 jours.

Imprimantes Bambu Lab (P1S, P1P, X1, A1)

  1. Sur l'imprimante : Settings → WLAN, activez LAN Only Mode ; avec les firmwares récents aussi le Developer Mode (affiché en dessous). Le code d'accès à 8 caractères est sur le même écran. Sans mode LAN, l'imprimante affiche son état mais ignore les impressions venant d'autres applications. En mode LAN, elle n'est plus connectée au cloud Bambu (Bambu Handy).
  2. Dans l'application : Add printer – l'imprimante apparaît comme « Bambu Lab P1S » (Android, à la maison) ou via Add a printer through the bridge. Saisissez le code d'accès ; le modèle d'imprimante est choisi pour vous.
  3. Imprimer : choisissez le bac de l'AMS pour chaque couleur ; l'image de la caméra, le timelapse et l'éclairage marchent comme sur les autres imprimantes.

Votre propre caméra (RTSP / webcam)

Pour les imprimantes derrière un pont : Settings → your printer → Own camera, saisissez p. ex. rtsp://utilisateur:motdepasse@192.168.1.60/live (Eufy : …/live0, Wyze : …/live, un Raspberry Pi avec mediamtx : rtsp://IP:8554/cam) ou l'adresse d'une webcam (http://IP/capture pour un ESP32-CAM). Elle remplace la caméra intégrée pour l'image, le timelapse et la détection d'erreurs. Caméra montée de côté ? Ajoutez #rotate=90 (ou 180, 270) à l'adresse – PocketPrint3D tourne l'image dans le sens horaire ; ce n'est jamais envoyé à la caméra. L'adresse est transmise chiffrée au pont. Serveur personnel : camera_url: dans config.yaml.

Multicolore (AFC / CANVAS)

Pour les modèles multicolores, choisissez l'emplacement de chaque couleur avant la préparation ; les emplacements vides sont signalés et le matériau suit le filament de l'emplacement. Pris en charge sur les imprimantes Klipper avec AFC (p. ex. Centauri Carbon avec COSMOS + CANVAS) et sur Bambu Lab avec AMS.

Vos propres profils OrcaSlicer

Settings → your printer → Printer profile : importez vos profils d'imprimante, de qualité et de matériau OrcaSlicer, ou collez le lien d'un bundle Orca Cloud public. Ils servent tout de suite au tranchage.
