Installer un pont

Avec un pont à la maison, vous accédez à vos imprimantes de partout et depuis le navigateur – état, caméra, impression, timelapse. Le pont se connecte uniquement vers l'extérieur : rien à ouvrir sur votre box, vos imprimantes restent hors d'Internet.

Vous avez déjà un serveur Unraid, Home Assistant ou une machine Docker ? Alors pas besoin de nouveau matériel : activez simplement Connect to PocketPrint3D Cloud dessus (modèle Unraid, option du module Home Assistant) – voir l'aide. Cette page est pour tous les autres.

1. Ce qu'il vous faut – environ 60 €

Disponible dans les boutiques d'électronique comme Kubii, The Pi Hut, Pimoroni ou Reichelt. Une seule fois : un ordinateur avec un lecteur de cartes (ou un lecteur USB pour quelques euros).

Pourquoi un câble ? Pas de Wi-Fi à configurer, une connexion plus fiable, et le pont trouve tout seul vos imprimantes sur votre réseau. Un Raspberry Pi Zero 2 W (Wi-Fi uniquement) marche aussi, mais avec la méthode décrite en bas de cette page.

2. Installation – environ 10 minutes, sans rien taper

Nous fournissons une image de carte prête à l'emploi : Raspberry Pi OS avec le pont déjà installé.

  1. Téléchargez l'image

    Télécharger l'image PocketPrint3D (environ 750 Mo, pour les Raspberry Pi 3, 4 et 5). Inutile de la décompresser.

  2. Écrivez-la sur la carte

    Installez Raspberry Pi Imager sur votre ordinateur (Windows, Mac ou Linux) et insérez la carte microSD. Dans l'Imager : Appareil : votre Raspberry Pi → Système d'exploitation : Utiliser une image personnalisée → le fichier téléchargé → Stockage : votre carte SD → Suivant. S'il propose de personnaliser les réglages : Non. Puis Écrire – cela prend quelques minutes.

  3. Branchez le Pi

    La carte dans le Pi, le câble réseau vers la box, l'alimentation en dernier. Le premier démarrage prend environ 3 minutes.

  4. Connectez-le dans l'application

    Avec votre téléphone sur le Wi-Fi de la maison, ouvrez l'application PocketPrint3D : Settings → Advanced → Print from anywhere. Le pont apparaît sous Found on your Wi-Fi – appuyez dessus. Puis Add a printer through the bridge – le pont trouve vos imprimantes tout seul. C'est fait !

Plus rien à faire ensuite. Le pont redémarre tout seul après une coupure de courant et installe la nuit les nouvelles versions et les mises à jour de sécurité.

Avec le navigateur au lieu du téléphone

Sur un ordinateur du même réseau, ouvrez http://pocketprint3d.local. La page affiche un code d'appairage (p. ex. K7Q4-M2ZX) : sur app.pocketprint3d.com, allez dans Settings → Advanced → Print from anywhere, saisissez le code → Connect.

Si quelque chose ne marche pas

L'application ne trouve pas le pont
Le téléphone est-il sur le Wi-Fi de la maison (pas en données mobiles) ? Un VPN sur le téléphone (p. ex. Tailscale) empêche la recherche : désactivez-le un instant. Le voyant de la prise réseau du Pi est-il allumé ? Après le premier démarrage, attendez 3 minutes, puis appuyez sur Search again. Sinon, ouvrez la page du pont (ci-dessus) et saisissez le code.
« pocketprint3d.local » ne s'ouvre pas
Cherchez l'adresse du Pi dans votre box (appareil « pocketprint3d ») et ouvrez-la, p. ex. http://192.168.1.42.
Le code a expiré
Il est valable 10 minutes ; la page en affiche un nouveau toute seule.
L'application indique « bridge offline »
Le Pi est-il alimenté et le câble réseau branché ? Après le branchement, il faut environ deux minutes.

Sûr par conception : l'image n'a ni mot de passe par défaut ni accès à distance (SSH) – personne ne peut se connecter au Pi. Le code d'appairage n'est affiché que sur votre réseau local. L'image est construite de façon transparente sur GitHub à partir de pi-image/.

Option : caméra Raspberry Pi

Vous branchez une caméra Raspberry Pi (p. ex. Camera Module v2) sur le Pi ? Elle est disponible tout de suite à l'adresse rtsp://IP-du-Pi:8554/cam – à saisir comme Own camera de votre imprimante dans l'application. Image à l'envers ? Ajoutez #rotate=180.

Autre méthode : l'installer vous-même

Pour un Raspberry Pi Zero 2 W (Wi-Fi uniquement), un Pi que vous utilisez déjà, ou n'importe quel ordinateur Debian/Ubuntu : installez Raspberry Pi OS Lite (64-bit) avec l'Imager comme d'habitude (avec le Wi-Fi et SSH dans ses réglages), connectez-vous avec ssh et lancez une seule commande :

curl -fsSL https://pocketprint3d.com/install-bridge.sh | sh

Elle installe Docker et le pont dans /opt/pocketprint3d-bridge et affiche le code d'appairage à la fin (à nouveau avec pocketprint3d-code). Lisez-la d'abord : install-bridge.sh. Questions ou problèmes : GitHub.
