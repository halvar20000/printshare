Set up a bridge

With a bridge at home you reach your printers from anywhere and from the browser – status, camera, printing, time-lapse. The bridge only connects outwards: nothing to open in your router, your printers stay off the internet.

Already running an Unraid server, Home Assistant or a Docker machine? Then you don't need new hardware: just switch on Connect to PocketPrint3D Cloud there (Unraid template, Home Assistant add-on option) – see Help. This page is for everyone else.

Available from electronics shops such as The Pi Hut, Pimoroni, Berrybase or Reichelt. Once: a computer with a card reader (or a USB card reader for a few euros).

Why a cable? No Wi-Fi to set up, a more reliable connection, and the bridge finds your printers on your home network by itself. A Raspberry Pi Zero 2 W (Wi-Fi only) works too, but needs the way at the bottom of this page.

2. Setting up – about 10 minutes, no typing

We provide a ready-made card image: Raspberry Pi OS with the bridge already on it.

  1. Download the image

    Download the PocketPrint3D image (about 600 MB, for the Raspberry Pi 3, 4 and 5). No need to unpack it.

  2. Write it to the card

    Install Raspberry Pi Imager on your computer (Windows, Mac or Linux) and put the microSD card in. In the Imager: Device: your Raspberry Pi → Operating system: Use custom → the downloaded file → Storage: your SD card → Next. If it asks about customising settings: No. Then Write – takes a few minutes.

  3. Connect the Pi

    Card into the Pi, network cable to the router, the power supply last. The first start takes about 3 minutes.

  4. Connect it in the app

    With your phone on your home Wi-Fi, open the PocketPrint3D app: Settings → Advanced → Print from anywhere. The bridge appears under Found on your Wi-Fi – tap it. Then Add a printer through the bridge – the bridge finds your printers itself. Done!

Nothing to look after afterwards. The bridge starts again by itself after a power cut and installs new versions and security updates at night.

Using the browser instead of the phone

On a computer on the same network, open http://pocketprint3d.local. The page shows a pairing code (e.g. K7Q4-M2ZX): at app.pocketprint3d.com go to Settings → Advanced → Print from anywhere, enter the code → Connect.

If something doesn't work

The app doesn't find the bridge
Is the phone on the home Wi-Fi (not mobile data)? Is the light on the Pi's network socket on? After the first start wait 3 minutes, then tap Search again. Otherwise open the bridge's page (above) and enter the code.
"pocketprint3d.local" doesn't open
Look up the Pi's address in your router (device "pocketprint3d") and open that, e.g. http://192.168.1.42.
The code has expired
It is valid for 10 minutes; the page shows a new one by itself.
The app says "bridge offline"
Does the Pi have power and is the network cable plugged in? After plugging in it takes about two minutes.

Safe by design: the image has no default password and no remote login (SSH) – nobody can log in to the Pi. The pairing code is only shown on your home network. The image is built openly on GitHub from pi-image/.

Other way: install it yourself

For a Raspberry Pi Zero 2 W (Wi-Fi only), a Pi you already use, or any Debian/Ubuntu computer: install Raspberry Pi OS Lite (64-bit) with the Imager as usual (with Wi-Fi and SSH in its settings), log in with ssh and run one command:

curl -fsSL https://pocketprint3d.com/install-bridge.sh | sh

It installs Docker and the bridge into /opt/pocketprint3d-bridge and shows the pairing code at the end (again with pocketprint3d-code). Read it first: install-bridge.sh. Questions or problems: GitHub.
