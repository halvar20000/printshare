Set up a bridge

With a bridge at home you reach your printers from anywhere and from the browser – status, camera, printing, time-lapse. The bridge only connects outwards: nothing to open in your router, your printers stay off the internet.

Already running an Unraid server, Home Assistant or a Docker machine? Then you don't need new hardware: just switch on Connect to PocketPrint3D Cloud there (Unraid template, Home Assistant add-on option) – see Help. This page is for everyone else.

1. What you need – about €60

PartWhat to look forapprox.
Raspberry Pi 3 Model B (or 3B+, 4, 5)A Pi 3 is plenty. It has an Ethernet socket – that matters.€38
Power supplyFor the Pi 3: micro-USB, 5 V, 2.5 A (ideally the official one). Pi 4/5: USB-C (3 A / 5 A).€10
microSD card16 or 32 GB, a brand card (e.g. SanDisk, Samsung).€8
CaseMatching the model, so nothing shorts.€6
Network cableFrom the Pi to your router (or a network switch). There's often one lying around.€3

Available from electronics shops such as The Pi Hut, Pimoroni, Berrybase or Reichelt. Once: a computer with a card reader (or a USB card reader for a few euros).

Why a cable? No Wi-Fi to set up, a more reliable connection, and the bridge finds your printers on your home network by itself. A Raspberry Pi Zero 2 W (Wi-Fi only) works too, but is harder to set up.

2. Setting up – about 20 minutes

  1. Install Raspberry Pi Imager

    On your computer: raspberrypi.com/software → download and install (Windows, Mac or Linux).

  2. Write the card

    Put the microSD card into the computer, start the Imager and choose: Device: Raspberry Pi 3 (or your model) → Operating system: Raspberry Pi OS (other) → Raspberry Pi OS Lite (64-bit) → Storage: your SD card.

  3. Settings in advance

    When the Imager asks whether to customise settings: Yes / Edit settings. Hostname: pocketprint3d · Username: pi + a password you remember · don't set up Wi-Fi · under Services: Enable SSH with password. Save, then Write – takes a few minutes.

  4. Connect the Pi

    Card into the Pi, network cable to the router, the power supply last. Wait two minutes – the green light blinks while it starts.

  5. Connect to the Pi

    Open a command window on your computer – Windows: Start → type Command Prompt; Mac: Applications → Utilities → Terminal. Type:

    ssh pi@pocketprint3d.local

    The first time type yes, then your password (it isn't shown while typing – that's normal).

  6. Install the bridge – one single command

    Copy this line, paste it into the window (right-click or Ctrl+V / ⌘V) and press Enter:

    curl -fsSL https://pocketprint3d.com/install-bridge.sh | sh

    On a Pi 3 this takes about 5–10 minutes. At the end your pairing code appears, e.g. K7Q4-M2ZX.

  7. Enter the code in the app

    In the PocketPrint3D app (or at app.pocketprint3d.com): Settings → Advanced → Print from anywhere → enter the code → Connect. Then Add a printer through the bridge – the bridge finds your printers itself. Done!

Nothing to look after afterwards. The bridge starts again by itself after a power cut and gets new versions at night. To see the code again: pocketprint3d-code (after step 5).

Without a command window

You can also use the Pi directly: connect a screen (HDMI) and a USB keyboard, log in with pi and your password and type the command from step 6.

If something doesn't work

"pocketprint3d.local" isn't found
Look up the Pi's address in your router (device "pocketprint3d") and connect to that address, e.g. ssh pi@192.168.1.42. Is the light on the network socket on?
A "32-bit" message while installing
The 32-bit system was written. Write the card again in the Imager with Raspberry Pi OS Lite (64-bit).
The code has expired
It is valid for 10 minutes; a new one appears by itself. Show it with pocketprint3d-code.
The app says "bridge offline"
Does the Pi have power and is the network cable plugged in? After plugging in it takes about two minutes.

Curious what the command does? Read the script first: install-bridge.sh. It installs Docker and the bridge into /opt/pocketprint3d-bridge. Questions or problems: GitHub.
